# Security policy

## Report a vulnerability

Please report suspected vulnerabilities in this marketplace, the Pi Security plugin, or Pi Security privately by emailing **contact@pi.security**. Do not open a public GitHub issue for a security problem.

We will acknowledge your report and keep you informed while we investigate.

## Protect sensitive information

Do not include secrets, credentials, access tokens, customer information, tenant names, private repository details, or non-public finding details in public issues, pull requests, discussions, or screenshots.

If reproducing a problem requires sensitive material, email us first and we'll arrange a secure way for you to share it.
